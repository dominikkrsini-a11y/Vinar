# Vinar marketing playbook

Human-in-the-loop marketing system for growing Vinar among **small wine producers** (OPG / hobby cellar) first, with wine lovers as secondary awareness.

An agent (or you) **drafts** weekly copy. **You** approve and publish. Nothing posts or spends ads by itself.

## Goals (30 days)

| Metric | Target |
| --- | --- |
| App installs | 100 |
| Users with ≥1 logbook entry (activated) | ~40 |
| Warm referrals collected | ongoing |

Activation beats vanity downloads. A user who never logs a wine is not a win.

## How to run a marketing session with an agent

1. Point the agent at `AGENT_BRIEF.md` + `WEEKLY_SYSTEM.md`.
2. Ask it to fill `drafts/<week>.md` from `templates/weekly-draft.md` (HR primary, EN twin).
3. Review the draft. Edit. Set `Status: approved`.
4. Publish **manually** (WhatsApp, FB, Instagram, in person).
5. Update [GROWTH_TRACKER.md](./GROWTH_TRACKER.md) and the Sunday KPI block in that week’s draft.

## Order of ops (do this before posting tips)

1. Activate people who already have the link (first wine + first entry).
2. Ask each activated user for 2–3 cellar friends.
3. One distribution touch (FB group **or** udruga **or** supplier).
4. Then educational posts.

## Hard rules (summary)

- Never publish or buy ads without explicit human approval.
- Max one post per Facebook group per week.
- No scraped cold spam.
- Croatian first for producer channels.
