# Weekly content + outreach system

Effort split for the 30-day user goal: **~70% activation / referrals / distribution**, **~30% educational content**.

## Cadence

| Day | Owner | Output |
| --- | --- | --- |
| Mon | Agent | Draft `drafts/week-NN.md` from `templates/weekly-draft.md` |
| Tue | Human | Edit, approve (`Status: approved`), plan send order |
| Wed–Sat | Human | Send DMs / post / visit per the week’s channel plan |
| Sun | Human | Fill KPI block in the same draft; note learnings for next Monday |

## Priority order inside every weekly draft

Always fill sections in this order (skipping is OK only if the tracker shows nothing left):

1. **Activation follow-ups** — downloaded but no first wine / entry  
2. **Referral asks** — activated users → 2–3 cellar friends  
3. **One distribution touch** — FB group **or** udruga **or** supplier (pick one primary)  
4. **Two educational posts** — from the pillars below  
5. **One soft CTA** — beta testers / invite a friend  

Do not lead the week with three tip posts if warm leads are still cold.

## Content pillars (rotate)

Always cellar-useful. HR primary, EN twin.

1. **Logbook speed** — sticky hands, 3 taps, ferment reading  
2. **SO₂ / pH** — calculator tip (honest: measure free SO₂ before dosing)  
3. **Fermentation problem** — stuck, temperature, yeast  
4. **Soft CTA** — beta invite, “pošalji u inbox”, ask a cellar friend  

## Channel mix (per week)

| Channel | Volume | Notes |
| --- | --- | --- |
| Personal DM / WhatsApp | 5–15 | Highest conversion; use `templates/outreach.md` |
| Facebook group | 0–1 | Soft ask; `templates/fb-group-post.md`; inbox CTA |
| Instagram | 0–1 caption | Optional until warm channels work |
| Udruga / offline | 0–1 touch | 15-min demo offer |
| Supplier / shop | 0–1 touch | Free listing now; paid feature later (human sells) |

## Weekly draft must include

- Status line (`draft` / `approved` / `done`)  
- Goal reminder (installs + activated users)  
- Sections 1–5 above with **HR then EN** under each asset  
- Sunday KPI block (even if empty at draft time)  
- Approval checklist from `AGENT_BRIEF.md`

## KPIs (Sunday)

Record in the week’s draft:

- DMs / messages sent  
- New installs (best estimate)  
- New activated users (≥1 logbook entry)  
- Referrals / names collected  
- Posts published (which channels)  
- One sentence: what to double down on next week  

Update rows in `GROWTH_TRACKER.md` whenever someone moves stage.

## What “good” looks like for Week 1–4

| Week | Focus | Rough target |
| --- | --- | --- |
| 1 | Activate existing links + ask for names | 15–20 installs, first activations |
| 2 | Warm referrals + 1–2 groups / udruga | 40–50 installs |
| 3 | One supplier or club demo | 70–80 installs |
| 4 | Every activated user invites one friend | ~100 installs / ~40 activated |
