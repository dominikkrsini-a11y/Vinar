## 1) Activation follow-ups (the 4 who already have the link)

Send these **before** any public post. Same text to each; personalize the name.

### Contact 1–4

**HR:**

```
Bok [ime], jesi li uspio otvoriti Vinara i upisati prvo vino + jedan upis u dnevnik (gustoća ili temperatura)?
Ako zapne prijava ili upis, javi odmah — popravit ću.
Cilj je da ti u podrumu ide brzo, ne da gubiš vrijeme na app.
```

**EN:**

```
Hey [name], did you open Vinar and add your first wine + one logbook entry (density or temperature)?
If login or entry sticks, tell me right away — I’ll fix it.
Goal is speed in the cellar, not spending time on the app.
```

If they reply “yes, done” → jump to section 2.  
If “not yet” → offer a 2-minute phone walkthrough (template B in `templates/outreach.md`).

```
Great — glad it’s working!
Do you know 2–3 other winemakers (same club / harvest / yeast shop) who’d want a fast logbook?
Forward this or just send names — I won’t spam, short beta ask only.

```

```
Što ima unutra:

Tko hoće link — javite se u inbox ili komentar “želim”, pošaljem privatno.
Bez plaćanja, tražim iskren feedback iz podruma.
```

**EN:**

```
Looking for 15–20 winemakers (small / hobby cellar) to beta-test Vinar during harvest and ferment.

What’s inside:
• fast logbook (density, temp, SO₂, racking…)

Free — I want honest cellar feedback.
```

## 4) Educational posts (two)

Post these **after** activation DMs and the soft FB ask — or in a second group / on Instagram.

### Post A — SO₂ / pH

**HR:**

```
Prije doze KMS-a: pH + slobodni SO₂. “Na oko” često pretjera ili ne štiti vino.

U Vinaru je kalkulator ciljanog slobodnog SO₂ (bijelo/crveno + pH). Beta link u inbox ako netko želi probati u podrumu.
```

**EN:**

```
Before dosing KMS: pH + free SO₂. Guessing often overshoots or under-protects.

Vinar has a free-SO₂ target calculator (white/red + pH). Inbox me for the beta link if you want it in the cellar.
```

### Post B — stuck ferment

**HR:**

```
Gustoća stoji, šećer još ima? Prvo temperatura i kvasac — ne odmah nova vrećica hranjiva “jer mora”.

Za praćenje očitanja na telefonu radim betu Vinara (dnevnik + savjet uz tvoja mjerenja). Inbox ako želite.
```

**EN:**

```
Density stuck, sugar still there? Temperature and yeast first — not another nutrient bag on autopilot.

I’m beta-testing Vinar for phone logbook + advice on your readings. Inbox if you want in.
```
