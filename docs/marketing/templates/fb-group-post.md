# Facebook group post template

**Rules:** max one post per group per week. Prefer “comment / inbox for link” over dumping store URLs in the first line (better replies, less spam flags).

---

## Soft beta ask (default)

**HR:**

```
Tražim 15–20 vinara (OPG / hobi / mali podrum) da testiraju besplatnu appu Vinara tijekom berbe i vrenja.

Što ima unutra:
• brzi dnevnik (gustoća, temp, SO₂, pretok…)
• kalkulator alkohola i slobodnog SO₂
• AI asistent koji gleda tvoja vina (ne generički chat)

Tko hoće link — javite se u inbox ili komentar “želim”, pošaljem privatno.
Bez plaćanja, tražim iskren feedback iz podruma.
```

**EN:**

```
Looking for 15–20 winemakers (small / hobby cellar) to beta-test Vinar during harvest and ferment.

What’s inside:
• fast logbook (density, temp, SO₂, racking…)
• ABV + free SO₂ calculator
• AI assistant that sees your wines (not generic chat)

Want the link — inbox me or comment “want it” and I’ll send it privately.
Free — I want honest cellar feedback.
```

**HR:**

```

U Vinaru ima kalkulator ciljanog slobodnog SO₂ (bijelo/crveno + pH). Ako netko testira betu, inbox za link.

**EN:**

```
Quick cellar reminder: before dosing KMS, measure pH and free SO₂ — guessing often overshoots or under-protects.

Vinar has a free-SO₂ target calculator (white/red + pH). If you want the beta link, inbox me.
